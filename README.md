# Catalog Creator Suite

Preciso fazer uma plataforma para editar e vizualisar um catálogo de empresa que fornece produtos alimiticios ( uma distribuidora)

A ideia de referencia base é o Adobe Acrobat (anexo01), quero reaproveitar a mesma ideia de layout, localização de ferramentas e etc.

não vamos utilizar as mesmas funções do produto original, apenas referencia de UI.

Na foto de anexo 2, segue as funções básicas que preciso para a plataforma.

vamos construir uma a uma as funções dentro da plataforma.

não quero hospedagem local.

a idéia é que o cliente possa utilizar de forma fácil a plataforma para editar o seu catálogo, ele precisa poder organizar as paginas, subir novas paginas, organizar seus produtos no grid, informações de descrição de produtos e mudar layout, tudo isso de forma fácil.

pense tambem em um tutorial da ferramenta completa com setas e texto indicando a ferramenta + função e um botão de ajuda para relembrar o tutorial.

eu ja tenho o catálogo em PDF pronto com todos os produtos, precisamos tornar ele editável nessa plataforma quando eu fizer upload, para poder exportar em PDF e link.
